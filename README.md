## 🚀 Proje Hakkında
`.tr-dev.top`, Türk yazılımcıların portfolyoları, açık kaynak projeleri, API'leri veya kişisel web siteleri için tamamen ücretsiz kullanabilecekleri bir alt alan adı projesidir. Bu proje, topluluğa destek amacıyla **HIZLI SORU ONLİNE ANONİM A.Ş.** altyapısı ile sunulmaktadır.

Bu depo (repository), `.tr-dev.top` web sitesinin açık kaynaklı kodlarını barındırmaktadır. 

## 📝 Nasıl Alt Alan Adı Alınır?

Kayıt işlemleri GitHub üzerinden **yapılmamaktadır**. Kendi `.tr-dev.top` alan adınızı saniyeler içinde almak için doğrudan web sitemizi ziyaret edin:

🔗 **[tr-dev.top Adresinden Hemen Başvuru Yap!](https://tr-dev.top)**

Web sitemizdeki formu doldurduğunuzda, talebiniz yöneticilerimize iletilir ve kısa süre içinde Cloudflare üzerinden güvenli bir şekilde aktifleştirilir.

## 💻 Geliştiriciler İçin (Açık Kaynak Katkısı)
Bu projenin web arayüzü herkesin katkısına açıktır. Eğer web sitemizin tasarımını (Tailwind CSS/HTML) geliştirmek, yeni özellikler eklemek veya hataları düzeltmek isterseniz:

1. Bu depoyu Fork'layın.
2. Kodlar üzerinde geliştirmelerinizi yapın.
3. Bize bir Pull Request (PR) gönderin.

## 📜 Kurallar ve Şartlar
* **Uygunsuz İçerik:** Küfür, hakaret, yasadışı içerik veya zararlı yazılım barındıran alan adlarına hizmet verilmez.
* **Telif Hakları:** Marka haklarını ihlal eden bilindik isimler (örn: `google`, `apple`) onaylanmaz.
* **Sorumluluk:** Projelerin içerik sorumluluğu tamamen alt alan adını kaydeden geliştiriciye aittir.
